## Portfolio Description

Android TV-style Kotlin app built for the Haystack News Android challenge, integrating Flickr search with a grid-based browsing UI and image detail screen.

Demonstrates a lightweight MVVM/repository flow using Retrofit, OkHttp, StateFlow, ViewBinding, RecyclerView, and Glide.

## Resume Bullet Variants

- Built a Kotlin Android TV-style photo search app integrating Flickr REST APIs with Retrofit/OkHttp and rendering searchable image grids with RecyclerView and Glide.
- Implemented MVVM-style state flow with ViewModel, StateFlow, lifecycle-aware collection, repository abstraction, and DTO-to-domain mapping.
- Added photo detail navigation, TV launcher support, externalized API key configuration, basic error UI state, and ViewModel unit tests.
